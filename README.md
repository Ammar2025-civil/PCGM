# VOID VANGUARD

A retro vertical space shooter in Python with pygame-ce. Every pixel and every sound is generated by the code. There are no image or audio files.

- 100 levels: 10 sectors × 10 levels, each with its own background, colours, enemies, music and one new mechanic
- A mini-boss every 5th level, a sector boss every 10th level, and a 4-phase final boss
- In-flight parts that visibly bolt onto your ship (spread cannon, wing guns, missiles, laser, rear gun, drones, shield, magnet)
- A hangar between levels with permanent upgrades and 12 ship hulls
- Combo multiplier, bullet grazing, golden ships, risk/reward pickups and optional challenges that earn stars

---

## 1. Check your Python version

Open **Command Prompt** (or PowerShell) and type:

```
python --version
```

If that doesn't work, try `py --version`. You need **Python 3.9 or newer**, and 3.11 or newer is best.

## 2. Install pygame-ce

If you ever installed the old `pygame` package, remove it first, because it clashes with pygame-ce:

```
python -m pip uninstall pygame
```

Then install pygame-ce:

```
python -m pip install pygame-ce
```

Check that it worked:

```
python -c "import pygame; print(pygame.version.ver)"
```

It should print a version number such as `2.5.8`.

## 3. Run the game

```
cd void_vanguard
python main.py
```

**The file to run is `void_vanguard/main.py`.** You can also run `python void_vanguard/main.py` from the repository folder.

## Controls

| Key | Action |
|---|---|
| Arrow keys or WASD | Move |
| (automatic) | Fire |
| Space | Bomb (clears bullets, hits everything) |
| P or Esc | Pause |
| F11 | Fullscreen on/off |
| Enter / Space | Confirm in menus |

A gamepad also works: stick or d-pad to move, A for bomb, Start to pause.

The main menu has only **Play**, **Continue** and **Mute**.

## How it plays

**A level** takes about 3 minutes. It starts with a title card that shows 3 optional challenges. Then come about 2 minutes of enemy waves in 4 acts (tense waves, then a short breather, with the last act being the "big wave"), a WARNING siren, and the end fight:
- levels 1-4 and 6-9 of a sector end with a **frigate**
- every 5th level ends with a **mini-boss**
- every 10th level ends with a **sector boss** that unlocks a new hull

**Dying** restarts the level, and the credits you picked up in that attempt are lost. Credits you already banked are safe. If you die 3 times on the same level, the game quietly gives you a little extra shield on the next try.

**Parts** drop from enemies. Glowing yellow **carrier** ships always drop one. Parts last until the end of the level:

| Pickup | Effect |
|---|---|
| S | Spread shot, level 1 to 5 |
| W | Wing guns, level 1 to 3 |
| M | Homing missiles, level 1 to 3 |
| L | Laser beam (pierces everything), level 1 to 3 |
| R | Rear gun, level 1 to 3 |
| D | Helper drone that orbits and auto-aims (up to your drone slots) |
| O | Shield bubble (absorbs one hit) |
| + | Repair 2 hull |
| B | +1 bomb |
| U | Credit magnet |
| ! | **Overdrive**: double firepower for 20 s, but your shield is switched off |
| $ | **Bounty Beacon**: double credits for 20 s, but enemies fire faster |

**Combo:** kill quickly to raise the multiplier from ×1 to ×8. Any hit resets it.
**Graze:** let bullets pass very close to your glowing core without touching it. You get points, a spark and a tick sound, and every 80 grazes earns a bonus bomb.
**Golden ships** appear in some levels and flee fast. Catch one for a pile of credits and a rare part.
**Stars:** each level has 3 challenges worth 1 star each. Stars unlock rewards at 10, 25, 40... up to 300 stars.

### The 10 sectors
1. **Earth Orbit**: formations, satellites drifting past
2. **Asteroid Belt**: rocks split apart, and green ore rocks drop extra credits
3. **Purple Nebula**: fog hides enemies, and lightning flashes a warning column before it strikes
4. **Ice Moon**: crystal walls bounce every bullet, yours and theirs
5. **Solar Flare Zone**: flares sweep the screen, so hide in the shadow under the floating debris
6. **Derelict Station**: narrow corridors, wall turrets, laser gates that flicker before they close
7. **Black Hole Rim**: gravity pulls your ship and all bullets to one side, and the side can switch
8. **Alien Hive**: nests keep spawning larvae until you destroy them
9. **Wormhole**: speed surges, warp tunnels full of credit orbs, and brief mirror flips
10. **Mothership Core**: everything mixed together, plus the final boss

## Saving

The game saves automatically to `void_vanguard/savegame.json` after every level and every hangar purchase. There is no save menu.

- To start over, choose **Play** on the title screen (it asks first), or delete `savegame.json`.
- If the save file is missing or damaged, the game starts fresh instead of crashing. A damaged file is kept as `savegame.broken.json`.

## Tweaking the game

You don't need to touch the game code to change the numbers:

| File | What you can change |
|---|---|
| `void_vanguard/level_data.py` | Level length, acts, breathers, the difficulty curve across 100 levels, enemy types and wave patterns per sector, hazard strength per level, golden ship chance, per-level overrides |
| `void_vanguard/shop.py` | Upgrade prices, max levels, hull stats and traits, star reward thresholds |
| `void_vanguard/config.py` | Player speed, hitbox, graze radius, fire rate, invulnerability time, combo tiers |

Save the file and run `main.py` again. Every level is generated from this data with a fixed seed, so a level plays the same way each time.

## Make a single .exe (Windows)

Easiest: double-click **`build_exe.bat`** in the repository folder. When it finishes, your game is at `void_vanguard\dist\VoidVanguard.exe`.

Or do it by hand:

```
cd void_vanguard
python -m pip install pyinstaller
python -m PyInstaller --noconfirm --onefile --windowed --name VoidVanguard main.py
```

Notes:
- You can copy `VoidVanguard.exe` anywhere. It saves `savegame.json` next to itself, or in `%APPDATA%\VoidVanguard` if that folder is read-only.
- The level data is baked into the .exe. If you edit `level_data.py`, run the build again.
- Some antivirus tools flag new PyInstaller builds as suspicious (a known false positive). Building it yourself on your own PC avoids most of this.
- The first launch of a one-file .exe takes a few seconds while it unpacks.

## Troubleshooting

- **"No module named pygame"**: run `python -m pip install pygame-ce` again, with the same `python` you use to run the game.
- **Errors mentioning pygame after installing**: you probably have both pygame and pygame-ce installed. Run `python -m pip uninstall pygame pygame-ce`, then `python -m pip install pygame-ce`.
- **No sound**: check that the game isn't muted (title screen) and that your audio device works. The game still runs without audio.

## Project layout

```
void_vanguard/
  main.py         <- run this: window, input, scene switching, saving after levels
  config.py       screen layout and player tuning
  level_data.py   <- all level numbers (edit me)
  levels.py       builds each level's timeline from level_data
  game.py         one level being played: collisions, combo, graze, challenges
  player.py       your ship, weapons, visible parts, drones
  enemies.py      enemy types, movement paths, wave patterns
  bosses.py       boss framework, frigate, 10 mini-bosses, 10 sector bosses
  hazards.py      the 10 sector mechanics
  bullets.py      projectiles and bullet patterns
  pickups.py      credits, ore and power-ups
  effects.py      explosions, debris, screen shake, freeze-frames
  hud.py          side panels, boss bar, intro card
  scenes.py       title, hangar, results and victory screens
  shop.py         upgrades, hulls, star rewards
  save.py         auto-save
  art.py          pixel-art generator and pixel font
  backgrounds.py  the 10 sector backgrounds
  audio.py        chiptune synthesizer, sound effects and music
tools/            test and development scripts (not needed to play)
build_exe.bat     one-click Windows .exe build
```
